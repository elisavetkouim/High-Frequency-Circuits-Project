# High-Frequency-Circuits-Project

The assignment was part of the course High Frequency Circuits (Electrical &amp; Computer Engineering, Aristotle Universuty of Thessaloniki).
This repository contains all numerical modeling, simulation scripts, and optimization algorithms used for this assignment.

## Overview:
### 1. Transimission Line Analysis & Matching
- Analytical load impedance calculation and stub tuning matching using the **Smith Chart**
- Reflection coefficient computation for a frequency spectrum
- Bandwidth study under conjugate matching conditions for various line lengths

### 2. Microstrip Filters & Parameter Optimization
- Analysis of a microstrip Low-Pass Filter (LPF) utilizing open-circuited stubs
- Optimization of the stubs' characteristic impedances for specific passband and stopband specifications

### 3. Non-Tree Network Solvers & Multi-Port Couplers
- Modeling a 4-port microwave directional network using $ABCD$ transfer matrices and Kirchhoff's circuit laws
- Computation of reflection coefficient, input impedance, power division, and output phase differences

### 4. Antenna Arrays & Radiation Patterns
- Radiated field synthesis for a linear horizontal array vertical $\lambda/2$ dipoles via the superposition principle
- Visualization of E-plane, H-plane, and 3D radiation patterns for inter-element spacings $d = \lambda/4, \lambda/2, 3\lambda/4$
- Directivity calculation using 2D numerical integration (Riemann sums)
- Analysis of a corner reflector antenna using the Method of Images
